# Chordra feedback

Tell us what Chordra should do next, or what isn't working. Everything here is public, so others can find your
request and add their 👍 to it.

**[Open an issue →](https://github.com/chordra-ai/feedback/issues/new/choose)**

| You want to… | Use |
| --- | --- |
| Ask for a feature | [Feature request](https://github.com/chordra-ai/feedback/issues/new?template=feature-request.yml) |
| Get a model or harness working (DeepSeek, Kimi, Cursor, …) | [Model or harness](https://github.com/chordra-ai/feedback/issues/new?template=model-or-harness.yml) |
| Report something broken | [Bug report](https://github.com/chordra-ai/feedback/issues/new?template=bug-report.yml) |
| Ask a question or share how you use Chordra | [Discussions](https://github.com/chordra-ai/feedback/discussions) |

Before opening a new issue, search the existing ones. If yours is already there, a 👍 on the first post counts
more than a "+1" comment.

Account, billing or anything private: email [contact@chordra.ai](mailto:contact@chordra.ai). Please don't post
API keys, tokens or private code here.
